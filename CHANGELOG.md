# Changelog

## v0.1.0 — 2026-10-06

First public GTA × Elden Ring source release, approved for publication by the project owner.

- Original native GTA Story Mode mod for Malenia, Starscourge Radahn, Fire Giant and Godfrey imports.
- Local asset conversion with pinned dependencies, original rigs/clips, material adaptations and a compiled texture-binding audit.
- GTA gun, explosive, vehicle and helicopter interaction; source-timed melee, stagger, defeat and reset.
- Multi-boss rival targeting, duplicate types, separate combat/effect state and whole-lineup reset.
- GTA-side fireballs, gravity traffic, city response, custom second phases and filming controls.
- Reversible private profile setup, checksum verification, source/native regression tests and public setup documentation.

The earlier core build has M3 gameplay evidence. The latest multi-boss and spectacle changes have build/offline-test coverage; they were not independently rendered for this release. Fresh-machine installation and new-feature performance remain unverified. No game assets or private playable package are distributed.

## v0.1.0-mac-setup — legacy prototype

Historical MW2 Terminal setup preview from before the GTA project direction. Preserved with its original code and credits; it is not a GTA × Elden Ring release.
